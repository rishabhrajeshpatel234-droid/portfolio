# Rishabh Patel - Personal Portfolio 💙🚪

A Doraemon-themed personal portfolio website built with pure HTML, CSS, and vanilla JavaScript (no external libraries or frameworks).

**Live Site:** [https://rishabhrajeshpatel234-droid.github.io/portfolio/](https://rishabhrajeshpatel234-droid.github.io/portfolio/)
*(Or open `index.html` locally in any browser)*

---

## 🌟 Highlights & Special Animations

1. **Anywhere Door (Dokodemo Door) 3D Transition**
   - Click "Open Anywhere Door" or "About" to trigger the vibrant 3D pink Dokodemo Door.
   - The door swings open with a 3D perspective animation, fills the screen with dimensional light, and zooms through the doorway into the **About** section.

2. **Gulliver Tunnel Swirl Transition**
   - Click "Home" or "Ride the Gulliver Tunnel Back to Home" to enter a hypnotic, swirling vortex of concentric rings that pulls the view inward before shrinking away to reveal the **Home** section.

3. **Flying Doraemon with Take-copter on Scroll**
   - Pure inline SVG illustration of Doraemon with zero external asset dependencies.
   - High-speed spinning Take-copter propeller and gentle floating bobbing animation.
   - Stays fixed on screen and glides across an S-curve path down the page as you scroll.
   - Holds a banner reading **★ RISHABH PATEL ★**.

4. **Context-Aware Typewriter Speech Bubble**
   - Types out *"I am a Python beginner, learning Systems and AI!"*
   - Dynamically updates as you scroll past different sections.
   - Click Doraemon to trigger tech trivia Easter eggs!

5. **Sections Included**
   - **Home**: Big greeting, student status at Newton School of Technology (NST), and Anywhere Door CTA.
   - **About**: Journey as a Python beginner and fascination with Computer Systems and AI.
   - **Skills & Gadget Inventory**: 4-D pocket cards for Python, Git, GitHub, and Systems & AI.
   - **Milestones**: Interactive timeline of learning at NST.
   - **Contact**: GitHub profile, NST link, and mailbox.

## 🚀 How to Run Locally

No build tools or package managers required. Simply:
1. Clone the repository:
   ```bash
   git clone https://github.com/rishabhrajeshpatel234-droid/portfolio.git
   cd portfolio
   ```
2. Double-click `index.html` or open it with your favorite browser:
   ```bash
   open index.html
   ```

## 🎨 Tech Stack
- **Structure**: HTML5 Semantic Elements
- **Styling**: Vanilla CSS (60fps hardware-accelerated animations using `transform` and `opacity`, `@media (prefers-reduced-motion)`)
- **Typography**: Google Fonts (*Baloo 2* and *Fredoka*)
- **Interactivity**: Vanilla JavaScript (no frameworks)
- **Character Graphics**: Pure inline SVG
